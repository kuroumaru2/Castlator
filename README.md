# Castlator

Real-time live chat translator with customizable inline styling and hover Romaji tooltips for [TwitCasting](https://twitcasting.tv/) streams.

## Features
- **Live Chat Translation:** Automatically translates incoming TwitCasting comments inline while keeping usernames intact.
- **Hover Romaji Tooltip:** Displays Romaji transliteration when hovering over Japanese comments or their translations.
- **Custom Styling:** Customize translation font color, size, and style (`normal`, `italic`, `oblique`) from the extension popup.
- **Multi-Language Support:** Translate comments into English, Indonesian, Japanese, Korean, Chinese, Spanish, and more.
